# Fase 3 — Definición (Paso 03)

## Objetivo
Cerrar el alcance del MVP y los criterios de éxito con metas medibles.

## Cambios
- `docs/requirements.md`: entregas por etapas (E1 WhatsApp, E2 IG + Messenger, E3 métricas), requerimientos funcionales y no funcionales, criterios de éxito, parámetros configurables, lo que queda fuera del MVP y las decisiones pendientes.
- `docs/project.md`: preguntas abiertas resueltas.
- `docs/roadmap.md`: Paso 03 cerrado.

## Validación
- Entrevista de 3 rondas con el usuario; las respuestas quedaron en `requirements.md`.
- Cada etapa tiene un "Hecho cuando" que se puede comprobar.
- Sin código: no aplica typecheck, lint ni tests.

## Decisiones
- 3 canales y 4 piezas en el MVP, entregados por etapas (unas 6 semanas en total; la primera entrega útil a las 3).
- Voz e imágenes desde E1.
- Mayorista: unidades, monto o el cliente lo dice; umbrales configurables.
- Horario, nombre y tono del agente configurables.
- Conversión: línea base el primer mes.
- Costo: alerta al 80 % de USD 100; no se apaga nada automáticamente.

## Pendientes
- BSP de WhatsApp, servicio de transcripción, tarifas oficiales de Meta y API de EFFI.
- Las metas propuestas (humano < 5 min, < 30 % escalado) se validan con el usuario en la operación.
